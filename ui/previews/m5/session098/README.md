# Phoenix UI static previews

These five 480x240 SVG files are generated by Session 098 from original
Project Phoenix tokens, text and normalized vector primitives:

- `home.svg`
- `communication.svg`
- `media.svg`
- `navigation.svg`
- `settings.svg`

They contain no firmware resources, scripts, embedded rasters, external
references or vehicle data. They demonstrate the offline host prototype only
and are not asserted to be compatible with the MMI firmware renderer.
