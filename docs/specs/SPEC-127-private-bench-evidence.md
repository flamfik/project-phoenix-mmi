# SPEC-127 - Private bench evidence

- Version: 1.0
- Maturity: ALPHA
- Evidence: Session 118
- Related questions: RQ-468-RQ-472

Physical evidence requires every prerequisite, a performed observation, safe
shutdown, one or more private capture hashes and a signed approval-record
hash. A triggered stop also requires completed stop response. Public output
contains no private hashes, identifiers, signatures or measurements.
