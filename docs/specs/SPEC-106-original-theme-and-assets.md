# SPEC-106 - Original theme and asset registry

- Version: 1.0
- Maturity: STABLE
- Evidence: Session 097
- Related questions: RQ-379-RQ-382

The Phoenix theme bundle contains eight colors, seven metrics, 23 text tokens
and six vector icons. Every icon is represented by project-authored vector
commands and marked `PROJECT_PHOENIX_ORIGINAL`. The registry must contain no
external references, firmware-extracted resources, navigation-media content
or vehicle identifiers.

The asset-byte metric is a reproducible host complexity measure, not a target
storage or rendering budget. Renderer compatibility remains unestablished.
