## Decision contract

The hypothesis is challenged by seven fixed tests spanning prefix length,
phase bias, delimiter alignment, delimiter divisibility, token reuse, record
header and address/length fields.

record contract. Three-byte alignment remains a candidate; record, address and
length models remain unestablished.
