# SPEC-123 - Bench recovery plan

- Version: 1.0
- Maturity: ALPHA
- Evidence: Session 114
- Related questions: RQ-452-RQ-455

Recovery covers safe power removal, de-energization, quarantine, evidence
sealing and review before retry. Normal shutdown, emergency cutoff and
reapplication lockout must first be rehearsed on a dummy load. Firmware,
EEPROM, Component Protection and vehicle-assisted recovery are prohibited.
