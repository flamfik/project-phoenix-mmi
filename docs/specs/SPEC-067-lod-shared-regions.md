# SPEC-067 - LOD shared regions

- Version: 0.1
- Maturity: ALPHA
- Evidence: Session 059
- Related questions: RQ-213-RQ-215

## Contract

All five sources are compared on a fixed 256-byte grid. Shared content is
classified only by aggregate entropy class and aligned continuity; bytes and
hashes are not published.

## Result

Thirty-four unique contents are shared by all sources, including 30
nontrivial contents. Thirty aligned blocks are identical, with a longest
consecutive run of 19 blocks. A single monolithic common core and record
decoder are not established.
