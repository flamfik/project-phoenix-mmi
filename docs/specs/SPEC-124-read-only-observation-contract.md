# SPEC-124 - Read-only observation contract

- Version: 1.0
- Maturity: ALPHA
- Evidence: Session 115
- Related questions: RQ-456-RQ-459

Only passive, post-gate observations may be classified. Raw capture remains
private and public output is aggregate-only. Storage access, updates,
configuration changes, Component Protection, active diagnostics and any live
vehicle or MOST connection remain denied.
