# SPEC-116 - Neutral navigation graph

- Version: 1.0
- Maturity: STABLE
- Evidence: Session 107
- Related questions: RQ-421-RQ-424

The neutral model contains ordered unique WGS84-E7 nodes and directed edges
with positive millimetre weights, road class and one-way classification.
Every edge endpoint must exist. A source provenance record is mandatory.
Public summaries omit coordinates and element IDs. No MMI or other proprietary
serialization is defined.
