# SPEC-115 - Navigation data provenance

- Version: 1.0
- Maturity: STABLE
- Evidence: Session 106
- Related questions: RQ-416-RQ-420

OpenStreetMap sources require `ODbL-1.0`, an attribution to OpenStreetMap,
source URI and snapshot SHA-256. Distribution requires a visible attribution
surface plus license and derivative-database review. Synthetic fixtures require
Project Phoenix provenance and their own hash.

Authoritative references are the
[OpenStreetMap copyright page](https://www.openstreetmap.org/copyright),
[OSMF attribution guideline](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)
and [OSM XML documentation](https://wiki.openstreetmap.org/wiki/OSM_XML).
This policy is not legal advice.
