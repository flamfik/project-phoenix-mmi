# SPEC-118 - Synthetic routing feasibility

- Version: 1.0
- Maturity: STABLE
- Evidence: Session 109
- Related questions: RQ-430-RQ-434

The deterministic host router applies distance-only Dijkstra to a validated
neutral graph. The fixed synthetic lab must demonstrate a reachable forward
route, a valid reverse alternative, one absent one-way reverse edge and one
unreachable disconnected route. Passing proves a host prototype only, not
production routing, target timing or MMI compatibility.
