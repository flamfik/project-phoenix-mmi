# Session 036 publication-safe evidence

Generated reports:

- `cd1-content-island-atlas.public.json`;
- `cd3-content-island-atlas.public.json`;
- `cd1-cd3.content-island-atlas.comparison.json`;
- `content-island-atlas-correlation.json`.

They contain artifact hashes, the unchanged envelope, two prior deltas, fixed
tile/grid parameters, generated IDs, file-relative offsets, aggregate byte,
word, entropy and histogram metrics, anonymous word-difference counts and
evidence statuses.

Firmware bytes, raw tile bytes, raw word or dominant-difference values, raw
strings, pointer values, absolute runtime addresses, local paths, map payloads
and extracted resources are excluded. The shifted-grid full tile report
belongs under ignored `work/`.
