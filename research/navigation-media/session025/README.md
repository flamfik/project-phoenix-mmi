# Session 025 publication-safe evidence

This directory contains generated, publication-safe evidence for the bounded
producer-first owner-caller candidate analysis:

- `cd1-owner-producer-candidates.public.json`;
- `cd3-owner-producer-candidates.public.json`;
- `cd1-cd3.owner-producer-candidates.comparison.json`;
- `owner-producer-candidate-correlation.json`.

The reports contain hashes, file-relative offsets, generated canonical
expressions, root classes, load displacements, owner-shape hashes, counts and
evidence status. They do not contain firmware bytes, instruction bytes,
absolute runtime addresses, raw strings, local paths, map payloads or
extracted resources.

Full local analysis output belongs under `work/`, which is ignored by Git.
